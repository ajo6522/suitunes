# Matched-input Pitcher comparison

The goal is measured pitch accuracy and natural vocal sound. Image-Line's internal algorithm is proprietary; parameter values and algorithms are not assumed equivalent. Its [Pitcher manual](https://www.image-line.com/fl-studio-learning/fl-studio-online-manual/html/plugins/Pitcher.htm) documents monophonic input, nearest enabled notes, Speed, minimum detection frequency, formants and distinct MIDI/octave modes.

1. Keep the unmodified 0.2 baseline/binary and source tag. Collect the user's failure excerpt and dry mono WAV plus the old key, scale, engine, Speed, Strength, mix, sample rate and FL settings. Do not use compressed/reverberated doubles as the only diagnostic input. Obtain permission before sharing anybody's recording externally.
2. Include annotated low/high singing, breathy vowels, sustained notes, vibrato, consonants, scoops, slides, rapid intervals, noise/silence and the generated corpus. Manually label intended note and voiced/unvoiced spans on natural vocals. Keep calibration and acceptance excerpts separate.
3. Make a new FL project with the exact same dry WAV on two clean routes, no reverb/compression/doubling. First render one route at a time to avoid accidental summing. Compare baseline, each Pitch Pop mode and Pitcher. Keep sample rate/bit depth/start/end fixed; log every control and software version.
4. For automatic G minor enable only G A Bb C D Eb F, reference frequency 440 Hz (Pitcher labels this A3; scientific MIDI calls it A4). Keep Strength/wrapper wet at 100%, gain equal and harmony off. Select an appropriate minimum input pitch in Pitcher; Pitch Pop currently has fixed mode-dependent lower bounds. Match perceived response, not numeric Speed values. MIDI testing must distinguish Pitcher's pitch-class mode from absolute octave mode; Pitch Pop uses absolute last-held MIDI.
5. Run Pitch Pop's offline tool at 1/40/100 ms and Strength 0/.5/1, with/without formant preservation in Quality. Repeat fixed shifter 0, +/-1, +/-3, +/-6, +/-12 semitone fixtures separately. Zero-strength/unity renders reveal coloration independent of note decisions. Fine Tune should use identical original-based edits for each comparison.
6. Measure actual output F0 independently. Plot dry detected F0, annotated target, selected target, requested/applied ratio and output F0 against time. Inspect octave flips and note onsets. Report median/p95 cents, >50-cent error, octave errors, note assignment, voiced precision/recall and unvoiced output artifacts by pitch range/vocal type. Do not exclude failures as "unvoiced" without recording them. Annotated natural vowels are necessary for formant/spectral-envelope measurements; a sine does not establish formant preservation.
7. Cross-correlate aligned bypass/active renders, compare declared PDC, and check impulse/attack alignment separately. Do not remove genuine correction transition delays when comparing responsiveness. Report plugin delay, detector observation time and live device round trip individually.
8. Match loudness without clipping, make randomly named A/B files, keep the identity key separate and listen blind on the same playback setup. Rate naturalness, pitch correctness, warble, consonants, onset smear, vibrato and voice identity. Note exact timestamps and repeat cases where Pitcher is preferred. No parity claim follows from one successful excerpt.
9. Benchmark Release after warmup, without simultaneous builds/scans, at the required sample rates/buffers and variable sequences. Record average/p95/worst callback time and deadline misses; treat any current-engine miss as a failed run requiring investigation. The included benchmark reports misses but does not hide them or substitute machine CPU percentage for FL behavior.

Acceptance targets from the research remain proposed until measured on curated natural vocals: >=99% target assignment, median detector <=5 cents, p95 <=20 cents, octave errors <0.5%, zero disabled-note targets, stable held notes and acceptable blind listening. Quality mode's 150 ms audio delay does not meet the aspirational <=10 ms goal. The low-delay engines lack formant preservation. Both tradeoffs remain visible.
