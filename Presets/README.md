# Custom presets only

No factory presets are installed or presented. Use the plug-in's Save control to create personal `.sts` files.
New files use UTF-8 JSON with `magic: SUITUNES_STS`, `format: SuitunesPreset` and `formatVersion: 1`.
Host-state schema versions are separate from the portable preset format. The prototype's older XML presets remain readable through the legacy loader.
